# Security Policy

## Supported Versions

Security updates and patches are actively applied to the following versions of **SRL (Serial Run Language)**:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :x:                |

---

## Reporting a Vulnerability

We take the security of **SRL** seriously. If you believe you have found a security vulnerability in the language runtime, FFI bridge, VM, or self-hosted compiler, please report it to us responsibly.

### How to Report

- **Do NOT** open a public GitHub issue for security vulnerabilities.
- Send an email to **emirtopay952@gmail.com** with the details of the vulnerability.

### What to Include

1. A clear description of the vulnerability.
2. Steps to reproduce the issue (including sample `.srl` code if applicable).
3. Potential impact of the vulnerability.

### Response & Handling

- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide a timeline for addressing the issue and releasing a patch.
- Credit will be given to the reporter upon public disclosure, unless anonymity is requested.
