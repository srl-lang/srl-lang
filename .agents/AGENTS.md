# SRL Project AI Assistant Rules & Guidelines

## 1. No Emojis Rule (Strict)
- Never use emojis anywhere in AI responses, user messages, documentation files (`*.md`), C++ source code (`*.cpp`, `*.hpp`), SRL scripts (`*.srl`), error logs, or console outputs.
- Keep all documentation headers and text plain, professional, and clean.

## 2. Communication Style
- Keep responses concise, direct, and structured using GitHub-style Markdown.
- Provide a summary of work done when ending a turn.
- Use clickable file links with `file://` scheme.

## 3. Language & Code Quality
- All source code, comments, logs, and example strings must be in English.
- Maintain C++17 clean architecture and cross-platform compatibility (Windows and Linux POSIX fallbacks).
- Ensure all tests pass before completing tasks.
