# Project Rules

1. Absolute Zero Emoji Policy: Emojis are strictly forbidden across documentation, source code, console output, and AI agent responses.
2. English Only: All code, docstrings, variable names, and error messages must be written in English.
3. Cross-Platform Parity: C++ features must compile cleanly on both Windows (MSVC) and Linux (GCC/Clang) via CMake.
4. Testing: All changes must be verified using srl run test scripts before committing.
