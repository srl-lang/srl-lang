# AI Guide for SRL Development

## Overview
SRL (Serial Run Language) is a hybrid C/Lua syntax programming language featuring a Bytecode Virtual Machine, Self-Hosted LLVM IR Compiler (`compiler/srlc.srl`), FFI C/C++ engine, DSP/FFT engine, and Qt GUI module.

## Workflow Rules
- Check `.agents/AGENTS.md` and `.agents/memory_bank.md` at the start of each session.
- Never insert emojis into files or agent responses.
- Verify CMake build and run test scripts before completing tasks.
